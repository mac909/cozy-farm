# Cozy Farm

A cozy seaside farming game for two, played together in the browser over the home Wi-Fi.

## Play

1. Start Docker Desktop, then run `npm run farm:up`.
2. On each laptop or phone, open `http://<this PC's IP>:8080`. To find the IP, run `ipconfig` and look for "IPv4 Address".

## Develop

1. Run `npm install` once.
2. Run `npm run dev`, then open the "Network" URL Vite prints. It works on phones on the same Wi-Fi too.
